# Komal Art Gallery Website

Premium, responsive redesign of the existing Komal Art Gallery GitHub Pages website.

## Files

- `index.html` — all website content and SEO structured data
- `styles.css` — visual design and responsive layouts
- `script.js` — mobile navigation, gallery filters, lightbox, animations and form enhancements
- `images/` — all original images, unchanged
- `images/optimized/` — smaller WebP copies used for faster page loading
- `robots.txt` and `sitemap.xml` — search-engine discovery files
- `admin/` — existing Netlify CMS files preserved
- `CNAME` — existing custom domain preserved

## Deployment

Upload the contents of this folder to the `main` branch of the existing GitHub repository. GitHub Pages should publish the changes automatically when the repository is already configured for the custom domain.

## Important content note

The antiques section uses elegant text-based museum cards because no antique photographs were included in the original ZIP. Add verified antique photographs later only after confirming each item’s details and image rights.
